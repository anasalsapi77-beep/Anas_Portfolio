# Anas Al Sapi — Cinematic Portfolio

A responsive, single-page portfolio built with semantic HTML, CSS and vanilla JavaScript.

## Included

- Cinematic dark visual direction with warm champagne accents
- Responsive desktop, tablet and mobile layouts
- Accessible mobile navigation and keyboard Escape handling
- Scroll progress, active navigation and section reveal animations
- Reduced-motion support
- Project showcase cards for the work described by the author
- Contact form that prepares an email using the visitor's email application

## Run locally

1. Extract the project folder.
2. Open it in Visual Studio Code.
3. Start `index.html` with the Live Server extension, or open the file directly in a browser.

No build tools or package installation are required.

## Before publishing

1. Confirm the phone number shown in the contact section.
2. Add your real GitHub and LinkedIn profile URLs once you have them. They are intentionally not represented by fake links.
3. Add repository and live-demo URLs to the project cards when the projects are published.
4. The hero artwork currently uses a custom initials-based visual because no profile photo was included with the supplied files. To use a photo later, add it to `assets/` and replace the hero artwork in `index.html`.
5. The contact form opens the visitor's email app; it does not send or store messages on a server. A hosted form service or backend is needed for direct website submissions.
6. Keep API keys, passwords and private data out of the public repository.
