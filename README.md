# Anas Al Sapi — Portfolio

A responsive single-page portfolio presenting my current studies, skills and practical web projects.

**Portfolio site:** [Open the portfolio](https://anasalsapi77-beep.github.io/Anas_Portfolio/) *(GitHub Pages deployment)*

## Built with

- HTML5 for semantic page structure
- CSS3 for layout, responsive styling and motion
- Vanilla JavaScript for navigation, scroll interactions and the contact form

## Included

- Responsive desktop, tablet and mobile layouts
- Accessible mobile navigation and Escape-key handling
- Scroll progress and active section navigation
- Section reveal effects with reduced-motion support
- Project summaries linking to the public repositories
- Downloadable one-page CV: [View updated CV](CV.md)

## Run locally

Open `index.html` in a browser, or run a static server from the repository root:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## GitHub Pages

A deployment workflow is included at `.github/workflows/pages.yml`. To enable it, open **Settings → Pages** and set the source to **GitHub Actions**. After that, pushes to `main` trigger deployment.

## Contact form

The form prepares an email using the visitor's email application. It does not submit to a backend or store messages on a server.
